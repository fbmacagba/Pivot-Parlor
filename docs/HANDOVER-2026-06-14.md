- **Always verify a frontend targets staging before data‑creating E2E:** login via it, take the `pp_session` token; it must be **200 on staging `/auth/me` and 401 on prod**. If 200 on prod → STOP.
- **Running E2E:** `E2E_BASE_URL` + `DEV_PASSWORD` in `.env`; `npx playwright test <specs> --workers=1` (single staging worker + shared DB → serial) on a **clean staging** (reset shops first via dev‑auth delete). Exclude `site-generation` (real AI; slow/credits) and `dev-shop-delete-repro` (diagnostic).
- **Login rate‑limit + E2E:** `/auth/login` has a 5/15min brake. PR #10 skips it only when `E2E_FIXTURES==="true"` **and** header `X-E2E-Test-Mock:1` (Playwright sends it; the BFF `login.tsx` forwards it). Anonymous staging traffic stays throttled; prod ignores the header.
